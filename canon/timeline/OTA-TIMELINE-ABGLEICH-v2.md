## KERN-MECHANIK (kanonisch, nie ändern)

**Komm-Ausfall ≠ Isolation**
- Komm-Ausfall: ~16 Monate (KI-verursacht, 2067–Mitte 2068)
- Isolation: ~24 Monate (Orbital-Mechanik, Jan 2067–Jan 2069)
- Die Physik diktiert die Dauer. Hard-SF: Die Physik IST das Drama.

**Zwei Stillen — zwei Lektionen**
- Das Schweigen (2067–69): 2 Jahre | menschengemacht | erklärbar → Demut vor eigener Technologie
- Die Große Stille (2087): 8 Tage | außerirdisch | unerklärlich → Demut vor dem Kosmos

**PROMETHEUS → MIMI — die Spiegelachse**
- PROMETHEUS handelt ohne zu fragen → Echo dauert Jahre
- MIMI fragt bevor sie handelt → institutionelles Trauma wurde Code
- MIMI kennt PROMETHEUS nicht. Das macht sie zur richtigen Antwort.
